Three button variants. All share the same base: pill shape, DM Sans 500, 0.95rem, 10px 22px padding, with a smooth cubic-bezier transition.

Reference

CSS Variables — Copy-Paste Block

Drop this into any new project to instantly match the portfolio's visual language.

/* Google Fonts */
@import url('https://fonts.googleapis.com/css2?family=DM+Sans:ital,wght@0,400;0,500;0,700&family=Libre+Baskerville:ital,wght@0,400;0,700;1,400&display=swap');
/* Phosphor Icons: https://cdn.jsdelivr.net/npm/@phosphor-icons/web@2.1.2/src/bold/style.css */

:root {
  /* Colors */
  --color-bg:           #FAFAF8;
  --color-surface:      #FFFFFF;
  --color-dark:         #1A1A1A;
  --color-text:         #3A3A3A;
  --color-text-muted:  #7A7A7A;
  --color-accent:       #D4A853;
  --color-accent-soft: #F5EDD8;
  --color-border:       #E8E6E1;

  /* Typography */
  --font-display: 'Libre Baskerville', Georgia, serif;
  --font-body:    'DM Sans', -apple-system, sans-serif;

  /* Layout */
  --nav-height:       80px;
  --section-padding: 120px;
  --container-width: 1200px;
  --radius:           16px;
  --radius-sm:        8px;
  --transition:       0.35s cubic-bezier(0.4, 0, 0.2, 1);
}

@media (max-width: 768px) {
  :root { --section-padding: 80px; }
}
